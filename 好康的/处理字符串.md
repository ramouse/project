## 查找子串

`find()方法`

```c++
size_t find(const string& str, size_t pos = 0) const; // 查找子串
size_t find(const char* s, size_t pos = 0) const; // 查找C风格字符串
size_t find(const char* s, size_t pos, size_t n) const; // 查找前n个字符
size_t find(char c, size_t pos = 0) const; // 查找单个字符

//如果没找到，返回std::string::npos;
//找到了，返回第一个符合要求的位置(索引，从0开始)
```

```c++
//例如：
//1.查找单个字符
string s = "Hello";
size_t pos = s.find('H');
cout<<pos;//输出 0 ;
//2.对查找字符串也同理，还可以指定从什么索引开始查找
size_t pos = s.find("ll",1);
cout<<pos;//输出 2 ；因为索引2是第一个符合"ll"y
```

getline(cin,s);//读取一行字符，直到遇到换行符，但不包括换行符
getlinee(cin,s,',')；//读取一行字符，直到遇到','时停止，s不包括','

## 进制转换

#### 十进制转2-16进制

```c++
int n;
string s;
int x;
char c;
for(int i = 2;i<=16;i++){
     int nu = n;
	 while(nu){
         x = nu%i;
         if(x<10){
             c = x+'0';
         }else{
             c = x+'A'-10;
         }
         nu/=i;
         s = s +c;
     }
    cout<<s<<endl;
}
```
