## 一 . 二分

### 1.二分查找

相信大家高中的时候学过二分法找零点，二分的思想就是折半，二分查找经常用于在有序数据上快速查找出符合要求的位置

举个例子，如果对于一个长度为 $n$ ，如果我们想要在上面找到一个元素的位置，暴力遍历数组，最坏情况下的时间复杂度达到 $O(n)$

但是我们使用二分查找，判断目前段中间位置的元素与目标元素的大小关系，就可以在$O(\log_2n)$（以下将$\log_2n$简写为$\log n$）的时间复杂度下完成查找

具体实现可以看下面的代码

```cpp
//我们令数组为1_index方式储存数据，即a[1~n]为有数据的地方
vector<int> a(n + 1);
int bisearch(const vector&<int> a , int x)
{
    int l = 1 , r = n;
    while(l <= r){
        int mid = l + r >> 1;
        if(a[mid] > x) r = mid - 1;
        else l = mid + 1;
    }
    return l;
}
```

我们可以看到，在上述代码中，每一次查询的区间的长度（即$r - l + 1$的值）在逐次$/2$，由此可见时间复杂度为$O(\log_2n)$。

同时我们注意到，左右端点都是跳跃的，因此我们需要保证我们的条件（在上面为 $a_{mid} > x$）和二分的东西是正（反）相关的，这也是二分法得以实现的一个重要条件，不满足这样条件的题目写一个错一个。想法不缜密，半夜一看被窝里全是WA。

### 2.二分的更多运用

这里对二分答案做一个例题讲解

[题面](https://ac.nowcoder.com/acm/contest/93268/E)（以下东西假设你读题完毕并已经理解题意）

题目需要我们确定最小的x满足条件

如果我们没有确定x的情况下，尝试决定每个物品放在第几次运输会非常麻烦，最终是否符合次数不少于k次更是无稽之谈。

此时我们发现，如果确定x时，我们只需要用$O(n)$时间复杂度遍历一遍物品，就能很轻松地完成运输次数的计算，此时可以和k比较来确定x是否可以符合题意

但是我们去看一下极限数据 
$$
a_i \leq 10^9  ,  q \leq n \leq 10^6
$$
也就是说，在极限数据下，x可能会从$10^9$到$10^{15}$！！！

换句话说，如果暴力枚举x，我们的极限时间复杂度可以达到惊人的$O(10^{15})$，暴力谁写谁爆炸。

怎么办呢？我们可以注意到，x越大，每一次可能装填的货物越多，对我们来说也就越有利

欸？这不就是正相关吗？！二分大人快救救我！！！

使用二分枚举x，我们可以把时间复杂度变为$O(\log10^{15} * 10^6)$，此时这个数字大概在$6 * 10 ^ 7$附近，可以在2s内完美跑完。

时间复杂度$O((\log {max(a_i)}) * n)$，实现代码如下

~~~cpp
#include<iostream>
using namespace std;
using ll = long long;
const int maxn = 1e6 + 5;
int a[maxn];
int n, k;
bool check(ll x)
{
    ll now = 0;
    int cnt = 1;
    for (int i = 1; i <= n; i++)
    {
        if (now + a[i] > x) {
            now = 0;
            cnt++;
        }
        now += a[i];
    }
    return k >= cnt;
}
void solve()
{
    cin >> n >> k;
    int maxi = 0;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        maxi = max(a[i], maxi);
    }
    ll l = maxi, r = (ll)maxi * n;
    while (l <= r)
    {
        ll mid = l + r >> 1;
        if (check(mid)) r = mid - 1;
        else l = mid + 1;
    }
    cout << l << endl;
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr), cout.tie(nullptr);
    int t = 1;
    cin >> t;
    while (t--)solve();
    return 0;
}
~~~

从例题我们发现，像这种最小的最大值的问题，我们很容易联想到二分答案。

## 2.递归

递归指的是自己调用自己的一种行为，通过修改参数可以达到改变所递归的过程，一般运用在分治和深度优先搜索（dfs）的核心函数上

我们直接通过讲解两种排序并附上底层代码来给大家看递归和分治的过程

#### 1>归并排序

归并排序基于二分的分治思想将数组分段排序后合并，具体将一个大无序数组分成两个（尽量）等长小数组，等待这两个数组有序后进行排序，对于数组中每一个元素最多被移动$logn$次，排序的时间复杂度从暴力的$O(n^2)$优化到$O(nlogn)$。

具体代码实现如下（使用std::merge）

```cpp
void merge_sort(vector<int>& a, int l, int r) {
  if (l >= r) return;
  int mid = l + r >> 1;
  merge_sort(a, l, mid);
  merge_sort(a, mid + 1, r);
  merge(a, front, mid, end);//这里std::merge指的是合并两个有序数组的函数
}
```

可以看到merge_sort函数反复调用自己，使得排序的数组的长度反复折半，从而达到分治效果。

一种排序没看够？再来一个！

#### 2>快速排序

快速排序一样是基于分治思想的排序算法，分为三个过程：

1. 将数列划分为两部分（要求保证相对大小关系）；
2. 递归到两个子序列中分别进行快速排序；
3. 不用合并，因为此时数列已经完全有序。

和归并排序不同，第一步并不是直接分成前后两个序列，而是在分的过程中要保证相对大小关系。具体来说，第一步要是要把数列分成两个部分，然后保证前一个子数列中的数都小于后一个子数列中的数。为了保证平均时间复杂度，一般是随机选择一个数$m$来当做两个子数列的分界。

同时注意到上述过程中，如果m被随机到边界，时间复杂度会变为$O(n^2)$，因此需要进行优化。

具体优化方法有很多，一一讲实在是太费时间了，这里给大家一个链接 [快速排序 - OI Wiki](https://oi-wiki.org/basic/quick-sort/)，感兴趣的可以自行查阅。

不感兴趣的不要紧，注意体会分治的思想即可。

## 三.递推

**前排提醒：递推和递推其实是两种东西**

递推指的是通过已有的信息推出新的信息的过程，一般会把这些信息整合到数组之中，形成递推式

拿一个大家都熟知的东西举例子：斐波那契数列。

众所周知，斐波那契数列的通项为
$$
f_n = 
\begin{cases}
0, &n=0
\\1,&n=1
\\f_{n-1} + f{n - 2},&n\geq2
\end{cases}
$$
我们可以看出，$f_n = f_{n - 1} + f_{n - 2}$就是通过$f_{n - 1}$和 $f_{n - 2}$推出了$f_{n}$，于是我们就说$f_n = f_{n - 1} + f_{n - 2}$是斐波那契数列的递推式。

因此，在代码中，我们如果要使用斐波那契数列，可以做以下的初始化

```cpp
const int maxn = 2e5 + 5;
int a[maxn];
void init()
{
	a[0] = 0;
    a[1] = 1;
    for(int i = 2 ; i <= 2e5 + 1 ; i ++)
    {
        a[i] = a[i - 1] + a[i - 2];
    }
}
```

这时我们调用a数组的某一个元素，就能得到斐波那契数列的某一项。

tips：递归递推的区别

我们可以看到，递归一般是由一个大范围的状态一直递归到小范围返回。递推则是从小的状态开始一步一步递推到大的状态，两者方向不同

其次，递归可以解决很多复杂的数据集合，而递推更多用来处理能用一个值的事情（其实就是事情的复杂程度）。

在最后，递归和递推的时间复杂度，递归的时间复杂度可能会很大，从$O(n!)$到$O(2 ^ n)$到$O(n)$到$O(logn)$不等，具体根据题目而定，而递推的时间复杂度通常为$O(n)$，并且伴有一定的空间复杂度用于储存递推的东西

因此在我们做题目的时候，我们需要灵活根据题目情况选择使用的方式，拿斐波那契数列来说，在不优化的情况下，如果用递归写，时间复杂度大概在$O(2^n)$左右，在一秒内只能跑$20$的数据，肯定不如递归$O(n)$跑$10^7$好，再拿上面的归并排序来说，我们无法通过递推完成这么多的任务，只能借助递归完成。

### 1.二叉堆

[二叉堆 - OI Wiki](https://oi-wiki.org/ds/binary-heap/)

二叉堆是一种完全二叉树，听不懂也没关系，现在只需要知道因为他是完全二叉树，他的层高不超过$logn$。

二叉堆的父节点总比它的子节点大（或小），这个是二叉堆的重要性质。

二叉堆有两个操作，插入和删除，这两个操作都是基于层间元素比较来进行的。

插入时从底部插入，如果子节点和父节点比较结果不满足二叉树的性质，二叉树会自动交换两层之间的元素使其恢复正常。

删除其实就是插入的反过程，相当于从把父节点设为0然后向下比较交换，最后将其删除就好。

至此二叉堆的性质和操作我们讲的差不多了，接下来看看我们要怎么使用二叉堆。

### 3.堆排序

堆排序，顾名思义就是通过二叉堆进行排序。

如果大家上面听懂了，会发现其实二叉堆本身就是一个自上而下有序的数据结构，那我们想要排序是不是就很简单了？把所有元素放进堆里再取出来就好了呀！

附上一个我自己去年在校内实验课上水的堆排序代码

```cpp
#include<queue>
template<typename T>
static void Sort(T* begin, T* end)//堆排为例
{
    std::priority_queue<T, std::vector<T>, std::greater<T>>pq;
    for (T* it = begin; it != end; it++) {
        pq.push(*it);
    }
    for (T* it = begin; it != end; it++) {
        *it = pq.top();
        pq.pop();
    }
    return;
}
```

每个元素进堆出堆各一次，每一次操作复杂度$O(logn)$，总时间复杂度$O(nlogn)$。

很简单粗暴对吧，感觉我在水时长一样（bushi）

虽然但是，其实堆排序很多情况下是很灵活的，因为二叉堆的性质，我们可以发现，在实现堆排序的过程中，放进堆的元素都是有序的，因此很多题目其实用优先队列实现堆排序简直不要太好做。

### 4.std::sort

在讲完这么多排序的原理之后，终于来到我们平常用的最多的函数之一，std::sort！

sort函数位于algorithm库中，用于对数组进行排序，并且会自动选择最合适的排序方法，总的来说是快速排序+基数排序，时间复杂度平均在$O(nlogn)$

```cpp
void sort(const _RanIt _First, const _RanIt _Last, _Pr _Pred)()
```

其中First是首地址/首迭代器，Last是尾地址/尾迭代器+1，Pred指的是比较方式，作用就是将First到Last之间的元素按照Pred进行排序，默认以less<>()排序。

### 5.Pred的重载

有的时候我们不希望只是简单的以大小关系比较进行排序，这时候我们需要重载cmp函数（即源码中的Pred）

具体可以看看下面的示范

```cpp
#include<bits/stdc++.h>
using namespace std;
bool cmp(int a,  int b)
{
    if(a % 2 == b % 2){
        return a < b;
    }
    else return a % 2 > b % 2;
}
int main()
{
	int a[5] = {1, 2, 3, 4, 5};
    sort(a , a + 5 , cmp);
    for(int i = 0 ; i < 5 ; i++)cout << a[i] << " ";
    return 0;
}
```

输出1 3 5 2 4，我们会发现输出的数组按照传入的cmp函数进行比较，最后排序。
