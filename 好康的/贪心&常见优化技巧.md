## 1. 贪心

**贪心(Greedy)** 可以说是最容易理解的算法思想,它指的是决策时都采取**局部最优选择**的算法,而面对相当数量的一部分问题,这样做确实可以获得最优解.

简单地说,贪心就是"走一步,看一步","只看眼前,不管将来".
把一整个问题分成多个步骤，每个步骤只关注目前的利益,而不考虑对后续步骤的影响,直至步骤结束,即贪心结束.

### 1.1 贪心与证明

由上述,可想而知,贪心并不是对所有问题都能得到整体最优解.

如果需要具体化**适用范围**的话,一般来说,能使用贪心的问题往往具有**最优子结构性质**,即一个问题的最优解包含其子问题的最优解,和**贪心选择性质**,即一个问题的整体最优解可以通过与一系列局部最优选择得到,而选择的贪心策略也必须具备**无后效性**,即某个状态以前的过程不会影响以后的状态.

贪心算法看着似乎并不靠谱,因为既不知道结果是不是全局最优,又**没有固定的算法框架**,有些时候甚至无法判断能不能使用贪心,因此在使用贪心解决问题前,往往需要**证明**使用的贪心策略是正确的.

#### 1.1.1 反证法

证明贪心的第一种方法,**反证法**.如果交换方案中任意两个元素/相邻的两个元素后,答案不会变得更好,那么可以推定目前的解已经是最优解了.

例 1.1.1 - [P2240 【深基12.例1】部分背包问题](https://www.luogu.com.cn/problem/P2240)

#### 1.1.2 归纳法

另一种证明方法是**归纳法**.每一步的选择都是当前的最优解,最后得到的当然就是全局的最优解.

例 1.1.2 - [P1803 凌乱的yyy / 线段覆盖](https://www.luogu.com.cn/problem/P1803)

#### 1.1.3 拟阵

除了反证和归纳法以外,还有一种更一般化的数学证明方法,**拟阵**.
拟阵理论是一种组合优化理论,但由于篇幅与难度原因,在此不做详细介绍.

### 1.3 贪心与反悔

除了上述利用类似**排序**的方法来解得答案的贪心外,还有另一种比较常见的贪心解法,**反悔**.
无论当前的选项是否最优都接受,然后进行比较,如果选择之后不是最优了,则**反悔**,舍弃掉这个选项;否则,正式接受,如此往复至最后.

## 2. 常见优化技巧

评价算法的标准,除了正确性以外,最重要的就是程序的**运行效率**是否足够高,是否可以在限定的时间内处理完指定的数据.

在暴力枚举时可以通过**剔除无效操作**来提升算法效率.然而除此之外,还可以用"**单调性**"和"**空间换时间**"来优化时间复杂度.将这两种思想结合,便产生了**单调栈**和**单调队列**等工具.
这些技巧可以帮助我们排除无效选项,在一定范围内保持单调性,常常可以将一些问题求解的时间复杂度降到O(n),因此称为**线性时间复杂度优化**.

### 2.1 双指针

双指针顾名思义,就是同时使用**两个指针**,在序列、链表结构上指向的是位置,在树、图结构中指向的是节点,通过**同向**移动,或**相向**移动来维护、统计信息.

1.利用**单调性**解决的问题可以尝试使用
2.本质其实是使用**队列**维护一个符合条件的区间,右指针增加相当于入队,左指针增加相当于出队

``` cpp
for (int i = 0, j = 0; i < n; i ++ )
{
    while (j < i && check(i, j)) j ++ ;

    // 具体问题的逻辑
}
```

优化前后区别:
优化前第二层遍历**从头开始**,优化后**从满足位置的地方开始**
时间复杂度由O($n^{2}$)降至O(nlogn)(需要排序,双指针时间复杂度本身为O(n)).

下面给出双指针的几个用法

#### 2.1.1 维护区间信息

不考虑算法间相互融合,双指针维护区间信息的最简单模式就是维护具有一定单调性,新增和删去一个元素都很方便处理的信息,比如正数的和,正整数的积等等.

例 2.1.1 - [P5745 【深基附B例】区间最大和](https://www.luogu.com.cn/problem/P5745)

#### 2.1.2 利用序列有序性

很多时候在序列上使用双指针之所以能够正确地达到目的,是因为序列的**某些性质**,最常见的就是利用序列的有序性.

例 2.1.2 - [P1102 A-B 数对](https://www.luogu.com.cn/problem/P1102)

#### 2.1.3 判断子序列

我们称一个串 x 是一个串 y 的**子序列**当且仅当在 y 中删除若干个(可以为 0 个)字符后得到的字符串与 x 相同.例如,bc,abc,a,abcd,abd 都是字符串 abcd 的子序列,但 dcba 不是.

例 2.1.2 - [392. 判断子序列](https://leetcode.cn/problems/is-subsequence/description/)

#### 2.1.4 数组的非线性排序(例如：大小大小....)

要求消耗最大，容易得到：从最大往最小（最小往最大）跳之后往此最大此最小跳即可，这是可以用**双指针**对当前的数组进行**重排**(重新排到新数组)   

此题本质还是**贪心**的思想

例 2.1.4 [P4995 跳跳！ - 洛谷](https://www.luogu.com.cn/problem/P4995?contestId=290509)

### 2.2 单调栈

顾名思义,内部元素具有**单调性**的栈
解决"**以某个值为最值的最大区间**"等类型的问题

``` cpp
常见模型：找出每个数左边离它最近的比它大/小的数
int tt = 0;
for (int i = 1; i <= n; i ++ )
{
    while (tt && check(stk[tt], i)) tt -- ;
    stk[ ++ tt] = i;
}
```

例 2.2.1 - [P2866 [USACO06NOV] Bad Hair Day S](https://www.luogu.com.cn/problem/P2866)

### 2.3 单调队列

顾名思义,内部元素具有**单调性**的队列
解决"**区间内最值**"等类型的问题

``` cpp
常见模型：找出滑动窗口中的最大值/最小值
int hh = 0, tt = -1;
for (int i = 0; i < n; i ++ )
{
    while (hh <= tt && check_out(q[hh])) hh ++ ;  // 判断队头是否滑出窗口
    while (hh <= tt && check(q[tt], i)) tt -- ;
    q[ ++ tt] = i;
}
```

例 2.3.1 - [P2032 扫描](https://www.luogu.com.cn/problem/P2032)
