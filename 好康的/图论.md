
## 图的概念

图有多种，包括 无向图 (边是无向的)，有向图 (边是有向的)，混合图 (两种边都有)

每条边上的值称为边的权值

简单图：若一个图中没有自环和重边，它被称为简单图。

- 自环：对𝐸中的边 𝑒 =(𝑢,𝑣)，若 𝑢 =𝑣，则 𝑒 被称作一个自环。

- 重边：若 𝐸 中存在两个完全相同的元素（边）𝑒1,𝑒2，则它们被称作（一组）重边。

迹：对于一条途径 𝑤，若 𝑒1,𝑒2,…,𝑒𝑘,两两互不相同，则称𝑤是一条迹。

路径：对于一条迹 𝑤，若其连接的点的序列中点两两不同，则称𝑤是一条路径。

回路：对于一条迹 𝑤，若 $v_0 = v_k$，则称 𝑤是一条回路。

环：对于一条回路 𝑤，若 $v_0 = v_k$ 是点序列中唯一重复出现的点对，则称𝑤是一个环。

子图：一张图的点集和边集是另一张图的对应集合的子集

## 图的遍历(存储)

邻接矩阵：使用一个二维数组 adj 来存边，其中 $adj[u][v]$ 为 1 表示存在 𝑢 到 𝑣 的边，为 0 表示不存在。如果是带边权的图，可以在 $adj[u][v]$ 中存储 𝑢 到 𝑣 的边的边权。

```cpp
int n, m, u, v;
cin >> n >> m;
vector<vector<pair<int, int>>> adj(n + 1, vector<int>(m + 1));
for(int i = 0; i < m; i ++) {
    cin >> u >> v >> w;
    adj[u][v] = adj[v][u] = {1, w};
}
```

邻接表：使用一个支持动态增加元素的数据结构构成的数组，如 $vector<int> adj[n + 1]$ 来存边，其中 adj[u] 存储的是点 𝑢 的所有出边的相关信息（终点、边权等）。

```cpp
int n, m, u, v;
cin >> n >> m;
vector<vector<int>> adj(n + 1);
for(int i = 0; i < m; i ++) {
    cin >> u >> v;
    adj[u].emplace_back(v);
    adj[v].emplace_back(u);
}   
```

## 剪枝

简单来说就是根据目前的状态已经可以知道最后得不到最优解时提前退出，分为记忆化剪枝，最优性剪枝

这种优化不是固定的，每个题目都有自己的优化方案，需要自己积累经验，但是基本方法就是上面两种

关键：通过提前退出递归来优化时间复杂度

[洛谷：棋盘](https://www.luogu.com.cn/problem/P3956)

```cpp
void solve(){
    int m, n;
    cin >> m >> n;
    vector<vector<int>> p(m + 1, vector<int>(m + 1, 0));
    vector<vector<int>> dp(m + 1, vector<int>(m + 1, -1));
    int x, y, s;
    fore(i, 1, n + 1) {
        cin >> x >> y >> s;
        p[x][y] = s + 1;
    }
    int ans = inf;
    vector<vector<int>> vis(m + 1, vector<int>(m + 1, false));
    auto dfs = [&](auto &&dfs, int x, int y, int sum, int st) -> void
    {
        if(dp[x][y] != -1 && sum >= dp[x][y]) return;
        if(sum >= ans) return;

        if(x == m && y == m) {
            ans = min(ans, sum);
            return;
        }
        vis[x][y] = true;
        fore(i, 0, 4) {
            int xx = x + dx[i];
            int yy = y + dy[i];
            if(xx < 1 || xx > m || yy < 1 || yy > m) continue;
            if(vis[xx][yy]) continue;
            if(p[xx][yy] == 0) {
                if(st != 0) continue;
                p[xx][yy] = p[x][y];
                dfs(dfs, xx, yy, sum + 2, 1);
                p[xx][yy] = 0;
            }else{
                if(p[xx][yy] == p[x][y])
                    dfs(dfs, xx, yy, sum, 0);
                else dfs(dfs, xx, yy, sum + 1, 0);
            }
        }
        vis[x][y] = false;
        dp[x][y] = sum;
    };

    dfs(dfs, 1, 1, 0, 0);
    if(ans == inf) cout << -1 << endl;
    else cout << ans << endl;
}
```

## 拓扑排序

我们可以拿大学每学期排课的例子来描述这个过程，比如学习大学课程中有：「程序设计」，「算法语言」，「高等数学」，「离散数学」，「编译技术」，「普通物理」，「数据结构」，「数据库系统」等。按照例子中的排课，当我们想要学习「数据结构」的时候，就必须先学会离散数学，教务处安排这些课程，使得在逻辑关系符合的情况下排出课表，就是拓扑排序的过程。

简单来说就是要做某件事之前必须做什么事，这种时候就要用到拓扑排序

**原理：**拓扑排序的核心思想是通过不断移除入度为 0 的顶点，并更新其邻接顶点的入度，直到所有顶点都被移除或无法继续移除。

### 算法步骤

1. 初始化

- 计算每个顶点的入度（即指向该顶点的边的数量）。

- 将所有入度为 0 的顶点加入队列。

2. 处理队列

- 从队列中取出一个顶点，将其加入拓扑排序结果。

- 遍历该顶点的所有邻接顶点，将其入度减 1。如果某个邻接顶点的入度变为 0，则将其加入队列。
  
3. 结束条件

- 如果所有顶点都被处理，则拓扑排序成功。
- 如果队列为空但仍有未处理的顶点，则图中存在环，拓扑排序失败。

```cpp
void solve() {
    int n, m;
    vector<int> ind(n + 1, 0);
    vector<vector<int>> p(n + 1);
    int u, v;
    fore(i, 1, m + 1) {
        cin >> u >> v;
        p[u].emplace_back(v);
        ind[v] += 1;
    }
    queue<int> q;
    fore(i, 1, n + 1) if(ind[i] == 0) q.emplace(i);
    while(!q.empty()) {
        int cur = q.front();
        q.pop();
        cout << cur << ' ';
        for(int to : p[cur]) {
            ind[to]--;
            if(ind[to] == 0) q.emplace(to);
        }
    }
}
```

## Dijkstra 算法求最短路

复杂度：nlogn 

这是一种单源最短路算法，运用了贪心思想。

初始化 𝑑𝑖𝑠(𝑠) =0，其他点的 𝑑𝑖𝑠均为 +∞

然后重复下面操作：	

寻找没有挑选过的点中的距离最小的点，之后对周围的点进行松弛操作（更新最短路），重复 n - 2 次

![image-20251128162653605](https://img2024.cnblogs.com/blog/3594125/202502/3594125-20250228223809175-1570694616.jpg)

```cpp
class Graph{
public:
    int n;
    vector<vector<pii>> adj;
    vector<int> vis, dis;
    explicit Graph(int n) : n(n){
        adj.resize(n + 1);
        vis.resize(n + 1, false);
        dis.resize(n + 1, 0x3f3f3f3f);
    } // 0x7ffffffffffffff
    void add(int u, int v, int w){
        adj[u].emplace_back(v, w);
        //adj[v].emplace_back(u, w);
    }
    void dj(int s){
        priority_queue<pii, vector<pii>, greater<pii>> pq;
        dis[s] = 0;
        pq.emplace(0, s);
        while(!pq.empty()){
            auto [d, cur] = pq.top(); pq.pop();
            if(vis[cur]) continue;
            vis[cur] = true;
            for(auto& [to, w] : adj[cur]){
                if(dis[to] > d + w){
                    dis[to] = w + d;
                    pq.emplace(dis[to], to);
                }
            }
        }
    }
};
```

## Floyd 算法求最短路

这个相比上一个可以求任意两个点之间的最短路，但是局限是复杂度很大，达到了 $n^3$ ,实现也比上一个简单，运用了动态规划思想。

我们定义一个数组 $f [k] [x] [y]$ ，表示只允许经过结点 1 到 𝑘（也就是说，在子图 𝑉′ =1,2,…,𝑘中的路径，注意，𝑥与 𝑦不一定在这个子图中），结点 𝑥 到结点 𝑦的最短路长度。

很显然，$f[n][x][y]$ 就是结点 𝑥 到结点 𝑦 的最短路长度

$f [k] [x] [y] = min(f [k-1] [x] [y], f [k-1] [x] [k]+f [k-1] [k] [y])$（ $f [k-1] [x] [y]$ ，为不经过 𝑘点的最短路径，而 $f [k-1] [x] [k]+f [k-1] [k] [y]$ ，为经过了 𝑘 点的最短路）。

```cpp
for (k = 1; k <= n; k++) {
  for (x = 1; x <= n; x++) {
    for (y = 1; y <= n; y++) {
      f[x][y] = min(f[x][y], f[x][k] + f[k][y]);
    }
  }
}
```

因为第一维对结果无影响，我们可以发现数组的第一维是可以省略的，于是可以直接改成 $f[x][y] = min(f[x][y], f[x][k] + f[k][y])$。这种其实更好理解，就相当于用一个新的点去尝试更新最短路，最后每个点都尝试更新过也就是最终结果了

局限性：没有局限性（只要有最短路就一定能求出来）。
注意：使用之前先对 $f$ 数组初始化，不能到达先设一个极大值。
