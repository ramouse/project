## 一、记忆化搜索

在正式开始dp之前先来一点前置开胃小菜——**记忆化搜索**。

记忆化搜索指的是把搜索到的东西当作一种状态用数组储存起来，以防反复搜索导致的时间空间浪费的一种优化方法。

我们请出我们的劳模斐波那契数列来给大家看一下具体实现和优化程度。

我们来看以下两种不同的搜索code：

```cpp																																											
//非记忆化优化
int dfs(int p)
{
    if(p == 1)return 1;
    if(p == 0)return 0;
    else return dfs(p - 1) + dfs(p - 2);
}
```

```cpp
//记忆化优化
const int maxn = 100 + 5;
int f[maxn];//f数组记录已经搜索过的
int dfs(int p)
{
    if(p == 1)return 1;
    if(p == 0)return 0;
    if(f[p] == 0)f[p] = dfs(p - 1) + dfs(p - 2);//如果没有记录，记录之
    return f[p];
}
```

我们将这两个函数放在分别在下面这两个题目上面跑一下

[B2064 斐波那契数列](https://www.luogu.com.cn/problem/B2064)附带结果	[非记忆化优化](https://www.luogu.com.cn/record/252299565)	[记忆化优化](https://www.luogu.com.cn/record/252299731)

[P1720 月落乌啼算钱（斐波那契数列）](https://www.luogu.com.cn/problem/P1720)附带结果	[非记忆化优化](https://www.luogu.com.cn/record/252301122)	[记忆化优化](https://www.luogu.com.cn/record/252301467)

我们可以看到，在数据量较小的情况下记忆化的优化聊胜于无，但是数据量较大的情况下优化效果出奇的好。

究其原因，是f数组储存了搜索的状态，使得这些状态可以复用，避免了重复搜索。

## 二、动态规划

### 1、动态规划基本思想

掰扯了半天记忆化搜索，那和今天的主题动态规划有什么关系呢？

在上面的记忆化搜索里，我称数组里面记忆（存放）的是搜索的**状态**，这个状态就是动态规划的核心所在。

动态规划的核心在于**状态转移方程**，通过状态转移方程我们可以快速得出其他状态的答案，从而得到题目要求的状态的答案。

和递推很相像对不对？动态规划其实有一部分是递推思想的具体实现，状态转移方程和递推式有异曲同工之妙。因此，动态规划具有递推的大部分优点，是一种效率很高的算法。

动态规划还可以用来解决很多最优解问题，此时动态规划的重点在于如何去设计状态和保证状态的合理性和数据的真实性。找到自己设定状态的状态转移方程，估算其时空复杂度，这些步骤正是动态规划算法的精妙与灵活所在，更是解决动规问题的乐趣所在。

## 2、动态规划使用条件

动态规划使用一共有三个条件：最优子结构、无后效性、子问题重叠。

最优子结构指的是当前最优是由以前的一个最优子状态更新而来，此点与贪心类似。

无后效性指的是当前状态的情况不会对后面状态的选择产生影响。

子问题重叠指如果有大量的子问题，我们需要尝试用类似记忆化的方式储存下来以免过度计算，具体与状态设计相关。

在我们做题的时候，考虑好这三个问题，自然就会很明白一个题目是否能用dp来做。

如果大家还想深入分析最优子结构和子问题重叠，欢迎大家在网上搜索或者前往oiwiki查询[动态规划基础 - OI Wiki](https://oi-wiki.org/dp/basic/)

## 三、背包问题

背包问题是运用dp解决的经典问题。

背包问题是指那些有一堆有费用和价值的物品，求选择这些物品的特定情况，比如最大值。

这些问题都具有典型特征，十分便于识别，是我们训练dp的不二选择。

因此，我们接下来会列举出几种常见的背包与其解决方案，大家可以体会其思路与做法。

另外向大家推荐一下背包问题经典著作《背包九讲》[背包九讲](https://github.com/tianyicui/pack)，本次课程并没有完全涵盖所有《背包九讲》内容，感兴趣的同学们可以深入学习一下。

### 1、01背包

01背包是所有背包问题的基础，其转移方程简单明白，最适合对背包问题的初见

01背包的物品通常只能决定选还是不选，即每一个物品的数量只能有一个。

我们来一到题目来常常01背包的咸淡：[采药 - 洛谷](https://www.luogu.com.cn/problem/P1048)

#### 1.朴素做法

由于每种草药只能采摘一次，我们只需要暴力遍历每一个草药，看看这一个草药摘不摘取，并整合最大价值情况就可以了。

此时我们来设计一下状态，令$dp[i][ti]$表示我遍历到第$i$株草药时，所用时间为$ti$的最大价值。

我们对于每一种草药来说，只有选择和不选择。

选择该草药时，有：$dp[i][ti] = dp[i - 1][ti - cost[i]] + val[i]$

不选择该草药时，有：$dp[i][ti] = dp[i - 1][ti]$

我们对上面两种情况取max，就可以得到我们想要的最大价值了。

于是我们遍历物品和我们被规定的所有可能的时间，我们可以得到以下核心代码：

```cpp
//采用1_index储存更直观
for(int i = 1 ; i <= M ; i ++)
{
    for(int j = 0 ; j <= T ; j ++)
    {
        dp[i][j] = max(dp[i][j] , dp[i - 1][j]);
        if(j >= cost[i]) dp[i][j] = max(dp[i][j] , dp[i][j - cost[i]] + val[i]);
    }
}
```

此时dp数组里面存有的就是我们所想要的最大值了，此时我们只需要对$dp[n][ti] , 0 \leq ti \leq T$取最大值，就能得出答案。

时间复杂度$O(M * T)$，空间复杂度$O(M * T)$

#### 2.滚动数组

重新回看状态转移方程，我们发现，$dp[i]$的值只由$dp[i - 1]$决定，那我们开$M * T$的数组岂不是太浪费了（悲）

于是为了优化我们的空间复杂度，我们可以另开一个数组$pre$代替这里的$dp[i - 1]$，将$dp[i][ti]$二维数组压到一维，在M较大的情况下可以优化很大一部分空间复杂度。

由于每一次$pre$数组都会被赋值当前$dp$数组的值，动态看起来像车轮滚滚向前，因此这种优化也被叫做滚动数组优化。

写起来很简单，只需要在上面的代码多加一个$pre$就行了，这里给大家看看核心代码：

```cpp
//采用1_index储存更直观
for(int i = 1 ; i <= M ; i ++)
{
    for(int j = 0 ; j <= T ; j ++)
    {
        dp[j] = max(dp[j] , pre[j]);
        if(j >= cost[i]) dp[j] = max(dp[j] , pre[j - cost[i]] + val[i]);
    }
    pre = dp;//滚动数组的滚动所在
}
```

附上此版本的ac提交记录：[记录详情](https://www.luogu.com.cn/record/252696866)

#### 3.还能进一步优化吗？

主播主播，利用$pre$数组还要多开$T$的空间，有没有不用开更多空间的做法？

有的兄弟有的，这里有一个直接把的$dp$数组压到一维的方法

从上面的代码中如果还想优化我们需要关注$dp$数组的复用。从状态转移方程来看，这样情况下$dp$数组只能由自己转移过来，并且对每个草药只能转移一次。

因此我们需要从设计费用的反方向遍历更新$dp$，这样可以保证新的$dp$一定时由没有考虑当前草药的老数据转移过来的。

说起来很绕口，理解起来可能有点困难，这里给出核心代码，大家可以复制以下然后输出每一次的dp数组看看区别：

```cpp
//采用1_index储存更直观
for(int i = 1 ; i <= M ; i ++)
{
    for(int j = T ; j >= cost[i] ; j --)//因为这里dp是从下往上转移的，这里对ti的遍历时从上而下遍历
    {
        dp[j] = max(dp[j] , dp[j - cost[i]] + val[i]);
    }
}
```

### 2、完全背包

完全背包与01背包的区别在于，完全背包的物品时无限个的，剩下的题目形式与01背包相差无几。

话不多说，来题：[疯狂的采药 - 洛谷](https://www.luogu.com.cn/problem/P1616)

其实就是上面01背包的题目改成完全背包了（嘻嘻）

先给出解决方法：直接让转移方向和遍历方向同向即可。下面给出核心代码：

```cpp
//采用1_index储存更直观
for(int i = 1 ; i <= M ; i ++)
{
    for(int j = cost[i] ; j <= T ; j ++)//因为这里dp是从下往上转移的，这里对ti的遍历时从上而下遍历
    {
        dp[j] = max(dp[j] , dp[j - cost[i]] + val[i]);
    }
}
```

ac记录：[记录详情](https://www.luogu.com.cn/record/252698614)

现在我们来讲一下为什么这么做。

在01背包压维的代码中，我们提到对于01背包需要保证新的$dp$一定时由没有考虑当前草药的老数据转移过来，而完全背包突破了草药数量的限制，此时我们反而需要这种带有重复访问的原始数据，即**每一次对新的物品遍历的时候满足已经遍历完前一个物品取的所有数量的情况**，此时我们只需要将01背包的遍历顺序逆转，就能得到完全背包的解决代码。

### 3、多重背包

多重背包也是01背包的一个变式。与01背包的区别在于每种物品有多个，既不是1个也不是无限个。

用最简单的思路来做，就是把多个物品的那个物品拆成多个一个物品当01背包做，此时时间复杂度为$O（m * \sum k_i）$。

然而有些题目很坏，光$k_i$都有$10 ^ 9$，这么办呢？

我们思考一个问题，如果我想用几个数字相加得到1e9以内的所有数字，最多需要几个数字呢？

欸是不是回到了数学问题？我们可以发现，当我们把数字二进制化，可以发现，最多只需要$\log n$个数字就可以了

因此，我们可以把$k_i$分成$\log{k_i}$个$2 ^ n$数量的物品，此时再做01背包，就可以完成对所有$k_i$的方案的便利了。

由于核心代码与01背包一致（其实01背包算是特殊的多重背包），只需要对物品（即输入）进行处理，此处不给出代码，大家可以自己试试看。

### 4、多维背包

上面所有背包的费用都是一维的，即限制只有一个

这类问题本质不难，就只是一维费用变为二位费用

值得注意的是各种费用可能符合各种上面的背包问题，此时需要对所有的费用进行遍历顺序或者扩展成多个物品的调整

这里给出核心code：

```cpp
//这里以第一维01，第二维完全举例
for(int i = 1 ; i <= n ; i ++)
{
    for(int j = m ; j >= cost[0][i] ; j ++)
    {
        for(int k = cost[1][i] ; k <= x ; k ++)
        {
            dp[j][k] = max(dp[j][k] , dp[j - cost[0][i]][k - cost[1][i]] + val[i]);
        }
    }
}
```

### 5、混合背包

混合背包也很简单，就是把上面几种背包总和在一起。

此时我们还是从输入下手，我们可以把物品分为有限个和无限个，把他们分别放在两个数组里。

在同一个dp数组上，对有限个物品的数组做多重/01背包，对无限个物品的数组做完全背包，最后得出的dp数组就是整体的dp数组啦。

核心代码和前面类似，这里不做赘述。

### 6、分组背包

分组背包会将若干个物品分到同一个组内，这些组中的物品最多只能选择一个。

因为在组里面选，我们从01背包的思路出发，暴力便利所有的组，在组数上进行状态转移，在套用01背包的核心代码，就能得到我们想要的结果啦

下面放上核心代码供参考：

```cpp
struct node {
	int cost = 0 , val = 0;
};
vcetor<vector<node>> zu;
//输入根据题目而定，下面的核心代码循环上界也要视情况而定
for(int i = 0 ; i < zu.size() ; i ++)
{
    for(int j = 0 ; j < zu[i].size() ; j++)
    {
        for(int k = m ; k >= zu[i][j].cost ; k--)
        {
            dp[k] = max(dp[k], dp[k = zu[i][j].cost] + zu[i][j].val);
        }
    }
}
```
