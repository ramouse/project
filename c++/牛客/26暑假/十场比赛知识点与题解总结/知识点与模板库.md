# 知识点与可复用模板库

这份文件不是“算法名清单”，而是用来回答三个问题：什么时候想到它、模板内部维护什么、放到具体题目里要改哪里。模板均按 C++17 书写；复杂算法只给稳定骨架和检查表，避免把只适用于某一道题的代码伪装成通用模板。

## 1. 并查集：动态连通块与“从大到小激活”

### 识别信号

- 元素按权值单调加入，询问只关心当前连通块。
- 一次合并后不会拆开。
- 处理顺序本身带有“时间/阈值”，合并时刻也要进入答案。

普通并查集只维护连通性；若还要记录“两个分量在什么阈值下第一次合并”，应建立 **Kruskal 重构树**：每次合并新建父结点，父结点权值就是当前阈值，原元素成为叶子。这样阈值问题会变成树上的祖先或路径问题。

```cpp
struct DSU {
    vector<int> p, sz;
    DSU(int n = 0): p(n), sz(n, 1) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        p[b] = a; sz[a] += sz[b];
        return true;
    }
};
```

### 本套题对应

- 第 1 场 C：按鱼的大小激活格点；合并阈值成为重构树权值。
- 第 6 场 A：不是重构树，而是并查集维护“还可放多少元素”的位置连通块；只有两侧分量仍有空位时，桥才可连通它们。

## 2. 树上小并大（DSU on map）

### 识别信号

每个子树要维护一个键集合/映射，父结点只是把所有孩子的集合合并，然后处理相同键的碰撞。每次总把小容器插入大容器，一个元素至多搬迁 `O(log n)` 次。

```cpp
using MP = unordered_map<long long, int>;

void merge_into(MP &a, MP &b) { // b 合并进 a
    if (a.size() < b.size()) a.swap(b);
    for (auto [key, id] : b) {
        auto it = a.find(key);
        if (it == a.end()) a[key] = id;
        else {
            // 按题意处理同 key 冲突；若三人同时碰撞，不能简单两两消掉。
        }
    }
    b.clear();
}
```

第 9 场 D 中同一结点的同 `key` 人员要 **全部死亡**。因此合并一批孩子时还要维护本结点已经发生碰撞的 `deadKey` 集合，第三个人到来后仍应死亡，不能重新留在 map 中。

## 3. Z 函数：一个字符串与所有后缀的 LCP

### 识别信号

题目反复比较 `s` 与 `s[i..]`，且只需要首个不同位置。Z 函数一次线性预处理就给出这些 LCP。

```cpp
vector<int> z_function(const string &s) {
    int n = (int)s.size();
    vector<int> z(n);
    for (int i = 1, l = 0, r = 0; i < n; ++i) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) ++z[i];
        if (i + z[i] - 1 > r) l = i, r = i + z[i] - 1;
    }
    z[0] = n;
    return z;
}
```

第 6 场 F：若某个后缀是 `s` 的真前缀，则 `s` 不可能比它小；否则在 LCP 后得到字符先后约束，26 个字母建 DAG，答案是拓扑序数量。

## 4. 子集 DP：拓扑序计数与固定最小未选元素

### 拓扑序计数

`pre[v]` 是 v 的所有前驱集合；`dp[mask]` 表示已经放置 mask。

```cpp
vector<Mint> dp(1 << n);
dp[0] = 1;
for (int s = 0; s < (1 << n); ++s) {
    for (int v = 0; v < n; ++v) if (!(s >> v & 1)) {
        if ((pre[v] & ~s) == 0) dp[s | (1 << v)] += dp[s];
    }
}
```

第 6 场 F 直接套用，状态数为 `2^26`；可以先按弱连通分量拆分，各分量分别计数，再乘分量操作的交错组合数。

### 三人分组

为消除“队伍顺序”的重复，每次强制取编号最小的未选成员 i，只枚举另外两人。

```cpp
long long solve(int mask) {
    if (mask == FULL) return 0;
    auto &res = memo[mask];
    if (res != NEG_INF) return res;
    int i = 0;
    while (mask >> i & 1) ++i;
    res = NEG_INF;
    for (int j = i + 1; j < N; ++j) if (!(mask >> j & 1))
        for (int k = j + 1; k < N; ++k) if (!(mask >> k & 1))
            res = max(res, score[i][j][k] + solve(mask | 1<<i | 1<<j | 1<<k));
    return res;
}
```

第 10 场 K 即此模板。分数允许负数，所以未访问态必须是负无穷，不能初始化为 0。

## 5. 数位 DP 中同时维护“数量、一阶和、乘积和”

若每个方案产生两个统计量 A、B，目标是 `sum(A*B)`，状态不能只保存方案数。保存四元组：

```text
cnt = Σ1, sa = ΣA, sb = ΣB, sab = ΣAB
```

加入当前位贡献 `x,y` 后：

```text
cnt' += cnt
sa'  += sa + x*cnt
sb'  += sb + y*cnt
sab' += sab + x*sb + y*sa + x*y*cnt
```

第 6 场 I 用它计算 `Σ popcount(i)·popcount(i+d)`。关键不是公式本身，而是加法进位方向与从高到低的上界 DP 相反：状态需要“猜测低位传来的进位”，再检查本位产生的高位进位是否等于状态要求。

## 6. XOR 线性代数与 XOR-FWT

### 线性基成员判定

固定配对后，先全选 A；把第 i 对改成 B 会异或一个 `A_i xor B_i`，可达集合就是这些差值的 span。

```cpp
struct XorBasis {
    long long b[63]{};
    void insert(long long x) {
        for (int i = 62; i >= 0; --i) if (x >> i & 1) {
            if (!b[i]) { b[i] = x; return; }
            x ^= b[i];
        }
    }
    bool contains(long long x) const {
        for (int i = 62; i >= 0; --i) if (x >> i & 1) x ^= b[i];
        return x == 0;
    }
};
```

### XOR-FWT

```cpp
void fwt_xor(vector<long long>& a) {
    for (int len = 1; len < (int)a.size(); len <<= 1)
        for (int i = 0; i < (int)a.size(); i += len << 1)
            for (int j = 0; j < len; ++j) {
                long long x = a[i+j], y = a[i+j+len];
                a[i+j] = x + y;
                a[i+j+len] = x - y;
            }
}
```

第 7 场 F 的关键转化：存在坏排列，当且仅当存在掩码 k，满足 `parity(k&t')=1` 且 A、B 中 `parity(k&x)=1` 的数量相同。设频数差为 c，FWT 后 `hat[c][k]=0` 恰表示两边数量相同；扫描全部 k 即可，复杂度 `O(d2^d+m)`。

## 7. Dinic 与最大费用流：先认清“容量约束的方向”

### Dinic 骨架

```cpp
struct Dinic {
    struct E { int to, rev, cap; };
    int n; vector<vector<E>> g; vector<int> lv, it;
    Dinic(int n): n(n), g(n), lv(n), it(n) {}
    void addEdge(int s, int t, int c) {
        E a{t, (int)g[t].size(), c}, b{s, (int)g[s].size(), 0};
        g[s].push_back(a); g[t].push_back(b);
    }
    bool bfs(int s, int t) {
        fill(lv.begin(), lv.end(), -1); queue<int> q; q.push(s); lv[s]=0;
        while(!q.empty()) { int v=q.front(); q.pop();
            for(auto &e:g[v]) if(e.cap && lv[e.to]<0) lv[e.to]=lv[v]+1,q.push(e.to);
        }
        return lv[t]>=0;
    }
    int dfs(int v,int t,int f){
        if(v==t) return f;
        for(int &i=it[v];i<(int)g[v].size();++i){ E &e=g[v][i];
            if(e.cap && lv[e.to]==lv[v]+1){ int d=dfs(e.to,t,min(f,e.cap));
                if(d){e.cap-=d;g[e.to][e.rev].cap+=d;return d;}
            }
        }
        return 0;
    }
    int flow(int s,int t){ int ans=0,f; while(bfs(s,t)){fill(it.begin(),it.end(),0);while((f=dfs(s,t,1e9)))ans+=f;}return ans; }
};
```

### 两类典型建模

- 第 5 场 G：二分图最小点覆盖转最小割。更深一层是跑完最大流后缩残量图 SCC，“所有最小割”对应残量 DAG 上的后继闭集。
- 第 8 场 K：一件物品对应从第一棵容量树穿到第二棵容量树的一单位流。第一棵边从根向下，第二棵从叶向根，物品边容量 1、费用为价值；流 k 单位即选 k 件。这里是最大费用流，不应误判成拟阵交。

费用流中请使用势能 + Dijkstra；题解明确提醒不要用 SPFA 作为主算法。

## 8. 虚树：只保留关键点和必要 LCA

### 识别信号

单次树询问只涉及 k 个点，要求复杂度与 k 而不是 n 成正比。将关键点按 DFS 序排序，加入相邻点 LCA，再用栈连边，虚树大小 `O(k)`。

```text
1. keys 加入根（若题目需要）并按 dfn 排序
2. 对相邻 keys 加入 lca
3. 再排序、去重
4. 栈顶不是当前点祖先时弹栈并连边
5. 当前点压栈
```

第 7 场 J 在虚树上做的不是普通“选/不选” DP：`F_u(c)` 的 c 是仍向父亲开放的链里包含多少关键点。压缩边的路径和、路径最小前缀要预处理；各儿子的状态集合通过动态凸包查询和小并大合并。

## 9. 压缩后缀树：重复子串的出现集合

### 识别信号

- 每个不同子串是一个状态，但 `O(n^2)` 个显式 trie 结点不可接受。
- 同一压缩边上的子串拥有相同出现位置集合。

后缀数组 + LCP 可建压缩后缀树：叶子对应后缀，内部结点深度为某段 LCP。边 `(parent,v)` 代表长度区间 `(dep[parent],dep[v]]`。

对应题目：

- 第 5 场 A：`W_v=子树叶权和`，边贡献为 `边长*W_v`；单点后缀权修改是叶到根路径加，查询是根到叶路径和，所以再套树链剖分。
- 第 8 场 E：后缀 trie 上的“前缀反链 DP”被压缩到后缀树。若某后缀从起点 i 起不含 p 的最长长度为 L，则压缩边上只有深度不超过 L 的隐式结点可选。

## 10. Manacher、回文树与回文后缀等差数列

Manacher 适合“一次求所有中心最大回文半径”；回文树适合维护每个前缀的不同回文后缀。第 6 场 L 更进一步用到性质：一个串的全部回文后缀可分成 `O(log n)` 个长度等差数列。

```cpp
vector<int> manacher_odd(const string& s) {
    int n=s.size(); vector<int>d(n);
    for(int i=0,l=0,r=-1;i<n;++i){
        int k=i>r?1:min(d[l+r-i],r-i+1);
        while(i-k>=0&&i+k<n&&s[i-k]==s[i+k])++k;
        d[i]=k--; if(i+k>r)l=i-k,r=i+k;
    }
    return d;
}
```

第 6 场 L 的跨拼接缝答案形如 `rev(V)+M+V`，M 是左串 A 的回文后缀。对每组等差数列只检查由周期串 LCP 定位出的常数个候选，LCP 用后缀数组 RMQ；所以每问 `O(log n)`，而不是枚举所有回文后缀。

## 11. 笛卡尔树：区间最小值递归结构

排列的最小笛卡尔树满足：任意区间 `[l,r]` 的最小值位置是其导出子树根。若操作总是删除区间最小值，笛卡尔树通常就是正确的递归结构。

第 8 场 L：左右段 SG 为 x,y，则本段 `mex{x,y,x xor y}`，值域只有 0,1,2。查询子区间时，沿笛卡尔树向上只是对三元小集合做函数复合，所以维护 3 元映射的倍增表即可每问 `O(log n)`。

## 12. 前缀容量、墙与区间加线段树

合法括号序列可写成右括号集合 R 的层状约束：

```text
|R| = n/2
|R ∩ [1,i]| <= floor(i/2)
```

定义剩余容量 `s_i=floor(i/2)-|R∩[1,i]|`，`s_i=0` 是“墙”。把右括号从 y 移到 x：

- `x>y`：区间 `[y,x-1]` 容量加 1，永远合法；
- `x<y`：区间 `[x,y-1]` 容量减 1，要求区间内没有墙。

第 10 场 M 的线段树因此维护区间最小值、D 的最大权、U 的最小权、墙前/墙后候选以及最佳合法交换。每轮根上取最大收益，做两个单点删除和一次区间加。这个模板可迁移到“在层状前缀约束下反复选择最优交换”的问题，但结点合并信息依赖题目，不能只复制普通懒标记线段树。

## 13. 滑动窗口 + 结构证书

### 识别信号

好区间向外扩仍好、坏区间向内缩仍坏，可以求每个左端的极大坏右端。但如果判定条件看似昂贵，要寻找坏状态的结构分类。

第 8 场 D 将互质看成图边。不存在两条不相交边的图，其非孤立部分只能是星或三角形；于是只维护“空图/单边/星/三角形”证书。点 j 的互质度用质因子子集容斥：

```text
deg(j) = Σ_{T⊆prime(a_j)} (-1)^|T| C[product(T)]
```

求得单调 `f(l)=极大坏右端` 后，询问 `[L,R]` 为 `Σ max(R-f(l),0)`，用分界点和 f 的前缀和回答。

## 14. Pollard–Rho 的使用边界

当数值到 `1e18`，但只需分解少量整数（如 `P+1`），线性筛不可用，采用 Miller–Rabin + Pollard–Rho。它是模板型工具，但实现较长且容易被乘法溢出破坏：

- 64 位确定性 Miller–Rabin 使用经过证明的一组底数；
- 模乘用 `unsigned __int128`；
- Pollard 迭代失败时更换随机常数重启；
- 得到质因子后排序压缩，再 DFS 枚举全部因子。

第 8 场 C 分解 `P+1` 后枚举因子 d，累计 `phi(d)*floor(n/d)`。本题不需要通用 floor-sum。

## 15. 概率阈值化与多项式插值

若随机变量非负整数，使用尾和：

```text
E[X] = Σ_{v>=1} Pr(X>=v)
```

若是 `[0,m]` 连续均匀分布，第 j 大的期望可直接用顺序统计量。

- 第 10 场 B：过程等价于从 `n+k-1` 个独立样本取前 k 大，直接求和，无需马尔可夫 DP。
- 第 10 场 C：固定阈值 i，只记录当前有多少台机器奖金至少 i；状态转移关于 i 是低次多项式。算出 `F(1..n+k)` 后，对前缀和多项式 G 做拉格朗日插值求 `G(m)`。

连续点 `0,1,...,d` 的拉格朗日求值可用前后缀积和阶乘逆，单次 `O(d)`；先判断目标点是否就在样本范围内。

## 16. 回滚莫队

普通莫队要求四种端点移动都容易撤销；若一侧只能方便地单调扩展，可按左端块分组：每组把右端从块末单调向右扩展，左端的临时修改做快照后回滚。

第 10 场 F 中右端单调扩展时可在正串 SAM DAG 上 O(1) 更新当前子串状态；左端临时扩展用反串 SAM，组结束回滚。复杂度 `O(n√q+q log n)`。这道题的正式主解不是“LCP 笛卡尔树二维贡献”。

## 17. 构造题的通用验证器思维

构造题通常没有可直接套的算法模板，但有稳定的工作流：

1. 写出必要条件/不变量。
2. 把构造拆成互不重叠的数值区间或状态族。
3. 独立写 `check()`，验证元素使用次数、范围和等式。
4. 对所有小规模参数跑构造并断言。

对应题：第 5 场 C（列与进位构成二点欧拉回路）、第 7 场 H（奇偶两套三元组）、第 9 场 A（构造后模拟类 BFS 计数）、第 6 场 K（图灵机必须配模拟器验证纸带与步数）。

## 18. 哪些内容不应伪装成“模板”

以下算法有通用理论，但本套题中的实现高度定制，适合保留“状态定义 + 推导 + 检查表”，不适合给一段似是而非的复制代码：

- 第 5 场 D 的精确三变量单纯形与 Farkas 系数恢复；
- 第 5 场 M 的特征 2 生成函数、复合逆和对角线系数递归；
- 第 7 场 B 的质数幂行列式计数、多点插值与 Pollard–Rho；
- 第 7 场 M 的 Graph Threading 到一般图最小权完美匹配；
- 第 8 场 J 的 BEST + Matrix-Tree + Burnside；
- 第 9 场 J 的模 `2^64` 截断 Stirling 展开；
- 第 9 场 K 的概率多项式线段树分治；
- 第 10 场 M 的墙线段树完整结点合并。

对这些题，逐题文档会明确列出证明链和实现组件，而不会仅写“套某模板”。
