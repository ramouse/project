Response:这道题的核心突破口在于题目中的一个关键条件：“保证 不小于之前放入过的所有鱼的大小”。v

这意味着鱼是按照大小非降的顺序被加入网格的。因此，每当加入一条新鱼时，它不仅是当前连通块中最新、最大的鱼，还能直接吃掉四周所有已存在的邻居鱼。这就带来了一个非常漂亮的树状拓扑结构，可以通过带路径压缩的权值并查集（WeightedDSU）来完美解决。

## 核心物理量与转化

我们可以把每次放入新鱼的过程看作是在构建一棵Kruskal重构树：

每条新鱼放入时，如果它挨着某些已有的连通块，它就会成为这些连通块根节点的双亲 $( \mathsf { P a r e n t } )$ o

由于新鱼的大小 之前的任何鱼，它一出生就能直接把这些子树里的鱼全吃掉。≥

对于一个已经在树中的老节点 $u ,$ ，如果它想借着后续不断加入的新鱼“游向更远的世界”（即扩大连通块），它必须能够一路向上走，跨越每一层父节点。假设 所在的某个历史连通块根节点为u $x ,$ ，现在它被合并到了一个大小为 的新父节点v $p$ 上：

1. 想要跨过 进入u x $^ { p , }$ ，它必须先吃完整个 子树内的所有鱼来壮大自 己。x

2.吃完 子树后， 的体型会增加x u $s z [ x ] - 1$ （其中 $\scriptstyle s z [ x ]$ 为 $_ x$ 子树内的总鱼数）。

3.此时 的体型为u $V _ { i n i t } + s z [ { \bf { \vec { x } } } ] - 1 { \bf { \vec { \tau } } }$ 。为了能吃掉父节点 $^ { p , }$ ，必须满足：

$$
V _ {i n i t} + s z [ x ] - 1 \geq v \implies V _ {i n i t} \geq v - s z [ x ] + 1
$$

因此，从子树根节点 跨越到父节点 的体型门槛（边权）为：x p

$$
W (x) = v - s z [ x ] + 1
$$

由于每条鱼只会被合并一次，一旦它从根节点变成了某个新节点的儿子，这条边权 就永远固定了！W(x)

## 权值并查集设计

我们用一个权值并查集来维护每个节点到它当前所属的大连通块根节点的路径信息。

parent[i]：节点 i 的父亲节点。

max\_w[i]：从节点i到parent[i]的路径上，最大的“门槛权值” 。W

sz[i]：以i为根的子树大小（仅对当前是根节点的i有效）。

## 路径压缩（Find操作）

在路径压缩时，我们不仅更新父亲指向，同时利用邻项求最大值的方式更新max\_w：

```c
int find(int i) {
    if (parent[i] == i) return i;
    int root = find(parent[i]);
    max_w[i] = max(max_w[i], max_w(parent[i]]);
    return parent[i] = root;
}
```

## 具体操作实现

操作 1：在 处放入大小为 的新鱼(x, y) v

1. 解密坐标，为当前位置新建一个节点 id。初始化 parent[id] = id, sz[id] = 1, max\_w[id] = -INF。

2. 检查 $( x , y )$ 四周的邻居。如果邻居有鱼，通过find找到邻居所在连通块的当前根节点r。

3.过滤出所有去重后的独特邻居根节点（避免重复合并同一个块）。

4.对于每个邻居根节点r：

记录边权： $\mathrm { m a x \_ w [ r ] \enspace = \enspace v \enspace - \enspace s z [ r ] \enspace + \enspace 1 }$

改变父亲： $\mathrm { p a r e n t } [ \mathrm { r } ] ~ = ~ \mathrm { i d }$

累加子树大小： $\mathrm { \ s z [ i d ] \Sigma \ + = \ s z [ r ] }$

5.答案：当前新鱼能吃掉的最大鱼数就是新连通块的总鱼数减去它自 己，即 $\mathrm { \ s { z } [ i d ] \ - \ 1 }$ 0

## 操作2：查询 处的鱼吃饱所需的最小增量(x,y)

1.解密坐标，找到该位置对应的节点id。

2.调用 find(id)。此时，id的父亲已经被压缩指向了当前整张网格的绝对根节点R，而 $\operatorname* { m a x } _ { - } \mathrm { w } \big [ \mathrm { i d } \big ]$ 存储的就是从id到R路径上的最高门槛值。

3.要想吃掉最多数量的鱼（即达到整个连通块的上限 $\mathrm { s z } \left[ \mathrm { R } \right] \mathrm { ~ - ~ } 1 )$ ），这条鱼的初始体型最低必须达到 $\operatorname* { m a x } ( \mathrm { s i z e } [ i d ] , \operatorname* { m a x } _ { - } w [ i d ] )$ c

4.答案：所需的最小增加量即为 $\operatorname* { m a x } ( 0 , \operatorname* { m a x } _ { - } w [ i d ] - \mathrm { s i z e } [ i d ] )$ 。

```cpp
const int INF = 2e9;

struct DSU {
    vector<int> parent;
    vector<int> max_w;
    vector<int> sz;
    vector<int> val; // 记录每条鱼的初始大小 v

    DSU(int n) {
    parent.resize(n + 1);
    max_w.assign(n + 1, -INF);
    sz.assign(n + 1, 1);
    val.resize(n + 1);
    for (int i = 0; i <= n; i++) parent[i] = i;
    }

    int find(int i) {
    if (parent[i] == i) return i;
    int root = find(parent[i]);
    max_w[i] = max(max_w[i], max_w(parent[i]]);
    return parent[i] = root;
    }

    void merge(int u, int v_parent, int val_p) {
    int root_u = find(u);
    if (root_u != v_parent) {
    max_w[root_u] = val_p - sz[root_u] + 1;
    parent[root_u] = v_parent;
    sz[v_parent] += sz[root_u];
    }
    }
};
```
