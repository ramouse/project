# 第 6 场逐题知识点与解法（A–L，共 12 题）

> 本场官方题解 PDF 未收录 E；E 节明确区分“由操作直接推出的严格结论”和实现方向，不再把推测写成官方算法。

## A. A Permutation Problem

- **主知识点**：从大到小激活“桥”、并查集维护可交换位置连通块。
- **辅助知识点**：乘法原理、连通块剩余容量。
- **识别信号**：局部峰 x 只允许交换两侧比 x 小的元素；按值从大到小处理时，x 恰好在当前成为新的桥。

大数 x 可让它左右两侧的小数跨过 x；在由已激活桥形成的连通位置块内，小于当前值的元素可以实现任意排列。按 `x=n..1` 决定 x 的最终位置：若 x 初始位置所在分量还有 S 个空位，则 x 有 S 种放法，答案乘 S，并把该分量空位数减一。

随后 x 尝试连通其初始位置左右两侧的分量。但若某一侧分量剩余容量为 0，说明其中全被大于 x 的数占据，x 无法跨越这些大数作为桥，不能合并；两侧均仍有空位时才合并。

- **模板**：[并查集与从大到小激活](知识点与模板库.md#1-并查集动态连通块与从大到小激活)。
- **复杂度**：`O(n α(n))`。旧版“奇偶位置不变量/笛卡尔树 DP”不是本题正解。

## B. CF2071B

- **主知识点**：不可避免贡献的下界、随机回溯构造。
- **辅助知识点**：前缀和检查、整数平方判定、随机重启。

长度 1 且值为完全平方数的子数组永远存在，共 `floor(sqrt(n))` 个；若总和 `n(n+1)/2` 为平方，整段也不可避免（`n<=5000` 时对应 8、49、288、1681）。官方结论是在范围内下界可达，目标是让其他所有区间和都非平方。

构造采用搜索：依次确定排列，下一个数随机枚举；放入 `a_i` 时检查所有新产生的后缀区间和，以及为了防止最终整段以外坏区间而检查相应剩余前缀条件。若走不通回溯。关键工程技巧是搜索状态超过 `2n` 便整次随机重启；官方对所有 n 做了多轮验证，成功率足够。

- **复杂度/性质**：这是随机化构造，没有确定的 `O(n)` 相邻交换贪心保证。平方判定使用整数平方根和 64 位前缀和。

## C. Cutting Trees

- **主知识点**：树形背包、两个独立操作序列的交错计数、统计量同步卷积。
- **辅助知识点**：组合数、删除时刻贡献转化。

一次删除后剩余结点数之和，可改写为每个结点被删除时刻之和减 n：若结点在第 i 次操作中直接或间接删除，贡献 i-1。

对 u 子树维护：`f[u][k]` 为不强制删除 u、执行 k 次的序列数；`g[u][k]` 为这些序列结束后剩余结点数总和；`h[u][k]` 为被删结点删除时刻总和。合并两个不交子树长度 i,j 时，内部顺序保持，交错数为 `C(i+j,i)`，f、g 做带组合数卷积。

h 还要计算另一序列插入后造成的时刻平移。第一序列第 r 次操作在所有交错中的位置和可由 `C(i+j+1,i+1)` 型系数得到，转移时同时乘另一侧的剩余结点统计。合并完孩子后，u 要么保留，要么作为最后一次操作删除整个剩余子树。

- **复杂度**：`O(n²)`。组合数不只是 f 的交错系数，h 的时刻平移系数不同，不能用普通树背包代替。

## D. Divisibility

- **主知识点**：奇偶扩展图 BFS、通过无向边往返补 2 步、同余向上取整。

路径允许重复边。在无向图中沿任意边往返一次增加 2，所以可达长度集合由“最短偶长/奇长路径”决定。把每个点拆为 `(u,parity)`，每过一条边翻转奇偶，BFS 得 `d[u][0/1]`。

- k 偶：k 的倍数只能是偶数。若 `d[u][0]=INF` 无解，否则向上取整到 k 的倍数。
- k 奇：k 的倍数奇偶交替。分别从两种最短奇偶长度向上取整，并检查所得倍数奇偶；官方化简式为 `min(d1+(-d1 mod k), d0+(-d0 mod k)+k)`，无穷项忽略。

- **复杂度**：`O(n+m)`。往返补长依赖无向边；有向图不能套此结论。

## E. 猫猫

- **严格操作等价**：给原元素 i 记被选次数 `c_i>=0`，`Σc_i=k`，最终值为 `min(a_i+c_i,m)`；所有 `c_i=0` 的元素保持原相对顺序，所有 `c_i>0` 的元素在最后一次操作时可任意插入，因此它们之间及与未动子序列可任意归并。
- **主知识点**：字典序最小化、保留子序列与可自由排列多重集的最优归并、把额外操作集中到牺牲元素。

固定被移动元素集合 S 后，每个元素至少花一次操作。剩余 `k-|S|` 次只会让值变大；按交换论证，应集中到最终归并中最靠后的牺牲元素，达到 m 后还可反复选择以浪费操作。其余移动元素只变为 `min(a_i+1,m)`。最终序列是“未移动的原序子序列”与“移动后值的有序多重集”的字典序最小归并。

可实现方向是从左到右维护保留骨架（单调栈处理删除/移动决策），并用按值桶或优先队列维护已移动元素的 `a_i+1` 候选；枚举牺牲元素/实际移动数的断点，比较保留头与移动多重集最小值，恢复最小归并。由于 `m<=2n`，桶可代替堆。

## F. Full Alphabet

- **主知识点**：Z 函数、Lyndon 串判定、DAG 拓扑序计数。

s 必须严格小于每个非空真后缀。若某后缀是 s 的真前缀（即 s 有 border），该后缀更短，s 不可能更小，答案 0。否则用 Z 函数求 `s` 与 `s[i..]` 的 LCP，首个不同字符 c,c' 给出字母顺序约束 `c<c'`。

26 个字母作点，约束作有向边。出现环则 0；每个合法字母表恰是 DAG 的一个拓扑序，用子集 DP 计数。可按弱连通分量拆开，分别计数再乘分量之间的交错组合数。

- **模板**：[Z 函数](知识点与模板库.md#3-z-函数一个字符串与所有后缀的-lcp)、[拓扑序子集 DP](知识点与模板库.md#4-子集-dp拓扑序计数与固定最小未选元素)。
- **复杂度**：字符串 `O(n)`，计数约 `Σ2^{|component|}`；按题意在 `uint32_t` 上自然溢出即模 `2^32`。

## G. Game Theory

- **主知识点**：逆向必胜集合、度数阈值的 bootstrap 扩张。

先把每个特殊点按邻边拆成多个叶状特殊点，不改变答案。考虑 Bob 先手时 Alice 必胜集合 W：点 u 属于 W，当且仅当 u 是特殊点，或至少有两个邻居在 W。度数不超过 3 保证两个分支独立；Bob 删掉一支，Alice 仍能走另一支并保持在 W。

从特殊点入队，维护每点已有多少 W 邻居，达到 2 时加入 W。回到原题 Alice 先手：她只需第一步走入 W，所以非特殊起点只要有至少一个 W 邻居即胜。

- **复杂度**：`O(n+m)`。扩张阈值是 2，最终起点判定阈值是 1。

## H. Hard Problem

- **主知识点**：字典序构造、质数差判定、小规模分类。

目标相邻差（首尾也相邻）均非质数。若 `n-1` 非质数，恒等排列 `1..n` 已合法且字典序最小。若 `n-1` 是质数，除 `n=3,4,6` 无解外，输出

`1,2,...,n-4,n,n-1,n-2,n-3`。

此时 n-1 为奇质数，n-4 为偶数且除小值外非质数；分类可证这是最早能改动的位置和最小后缀排列。`n=2` 可行。

- **复杂度**：判素数后 `O(n)` 输出。

## I. Integer Function

- **主知识点**：二进制数位 DP、逆方向进位、同时维护乘积统计。

从高位到低位做 `i<=n` 的数位 DP，但 `i+d` 的进位从低向高传。状态记录当前位要求向高位提供的进位 c；枚举本位时猜低位传来的进位 nc，并检查本位运算产生的 c 是否匹配。

每个状态维护 `cnt, ΣA, ΣB, ΣAB`，A/B 分别是原数和加 d 后的 popcount。加入当前位 x,y 时用

`(A+x)(B+y)=AB+xB+yA+xy`

做线性转移。

- **模板**：[数位 DP 的四统计量](知识点与模板库.md#5-数位-dp-中同时维护数量一阶和乘积和)。
- **复杂度**：`O(log(n+d))` 乘常数状态；最高位后要确认残余进位。

## J. Just Add and Divide

- **主知识点**：糖水不等式、点集凸包上的最大斜率查询、根号分块。

查询实际为 `max (a_i+a_j)/(b_i+b_j)`。令 k 是区间内 `a_i/b_i` 最大者。对任意不含 k 的一对 i,j，糖水不等式表明用 k 替换比值较小的一端不会变差，所以最优对必含 k。

固定 k 后，目标是对 j 最大化 `(a_k+a_j)/(b_k+b_j)`；几何上是点 `(b_k,a_k)` 到 `(-b_j,-a_j)` 的斜率，可在候选点凸包上二分切点。

数组按 `sqrt(n)` 分块：单点修改重建块凸包；查询先 RMQ 找 k，散块暴力，整块在凸包二分。

- **复杂度**：默认 n、q 同阶约 `O(n√n logn)` 总量；精细可到 `O(n√(nlogn))`。分数比较用 `__int128` 交叉乘。旧版写成线段树 `O(log²n)` 不是官方复杂度。

## K. Konstruct

- **主知识点**：图灵机宏状态设计、固定宽整数块的纸带搬运、构造验证。

纸带每 16 位为整数块，目标在第 0 块写 `#{a_i>k}`。标程生成约数千个有限状态，实现四种宏：复制 16 位整数、二进制减一并判零、四块循环移动、16 位比较与答案加一。

先把 n 复制到第 0 块。正向扫描 n 轮，每轮减计数器并把窗口 `(counter,n,k,a_i)` 循环右移，最终纸带为 `(a_0..a_{n-1},0,n,k)`，中间 0 作答案。再反向扫描：每轮把 `(a_{i-1},ans,i,k)` 循环左移，比较 `a_{i-1}` 与 k，若大则 ans++。计数器归零时答案恰回到第 0 块。

- **模板**：[构造验证器](知识点与模板库.md#17-构造题的通用验证器思维)。必须写图灵机模拟器验证所有状态/符号转移、最终纸带和步数；官方上界 `4847n+625<4e8`。

## L. Longest Palindromic Substring Queries

- **主知识点**：回文树的回文后缀等差数列、后缀数组 LCP、单峰候选定位。
- **辅助知识点**：Manacher 预处理完全位于两侧的答案。

删除区间后得到前缀 A、后缀 B。答案分为完全在 A、完全在 B、跨接缝三类。跨缝回文一定形如 `rev(V)+M+V`，其中 M 是 A 的回文后缀；对每个 M 要求 `V=LCP(rev(A)[|M|..],B)`。

A 的回文后缀最坏 O(n)，但可由回文树分成 `O(logn)` 个长度等差数列，每组形如 `W,D+W,D²+W,...`。在一组内上述 LCP 随项位置具有单峰结构，最优只在由 `LCP(D^∞,...)` 定位出的常数个下标附近。LCP 用后缀数组+RMQ。

- **模板**：[Manacher/回文树专题](知识点与模板库.md#10-manacher回文树与回文后缀等差数列)。
- **复杂度**：预处理 `O(nlogn)`，每问 `O(logn)`。只用哈希枚举所有回文后缀会退化到平方。
