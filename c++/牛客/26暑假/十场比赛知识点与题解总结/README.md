## 重要纠错

新题解材料使旧版若干分类得到修正，例如：

- 第 6 场 A 是“从大到小建桥 + 并查集容量”，不是笛卡尔树 DP；J 的官方实现是根号分块 + 凸包。
- 第 8 场 C 是 gcd 求和 + Pollard–Rho；K 是两棵容量树间的最大费用流，不是拟阵交。
- 第 9 场 G 的可实现核心是带权点覆盖与 min-plus 滑窗；E 是对禁入度集合容斥。
- 第 10 场 B 可直接化成顺序统计量；D 需要孩子—颜色二分匹配；F 的主解是正反 SAM + 回滚莫队；M 是“墙”线段树贪心。

第 6 场 E《猫猫》在提供的正式题解 PDF 中只有难度表、没有正文。该题文档明确给出能够由操作严格推出的标准形，并对尚未由官方材料确认的实现细节作了标注，没有把猜测包装成结论。
