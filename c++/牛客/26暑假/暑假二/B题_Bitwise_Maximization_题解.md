# B 题 - 按位最大化（Bitwise Maximization）

## 题目大意

给定一个长度为 $n$ 的非负整数数组 $A$，将每个元素放入两个多重集合之一（可以为空）。分别计算两个集合的**异或和**（XOR sum），求这两个异或和相加的**最大值**。

- $\sum n \leq 5 \times 10^5$
- $0 \leq A_i < 2^{30}$

---

## 核心观察

### 观察 1：总异或和是常数

设整个数组的异或和为 $X = A_1 \oplus A_2 \oplus \cdots \oplus A_n$。

对于任意一种划分，设两个集合的异或和分别为 $S_1$ 和 $S_2$，则有：

$$S_1 \oplus S_2 = X$$

这说明 $S_1$ 和 $S_2$ 的异或结果始终等于 $X$，不受划分方式影响。

### 观察 2：$X$ 中为 $1$ 的位无法优化

对于 $X$ 中值为 $1$ 的二进制位（即 $X$ 的某一位是 $1$），由于 $S_1 \oplus S_2 = X$，该位上 $S_1$ 和 $S_2$ 一定一个是 $0$、另一个是 $1$。

因此无论怎么划分，这些位对答案的贡献固定为 $1$（即贡献大小等于该位的位权）。

> 设 $X$ 中为 $1$ 的位的位权之和为 $fixed = X$ 本身（因为这些位无论如何都是 $0+1=1$，贡献固定）。

**实际上**：$X$ 中为 $1$ 的位对最终答案的贡献总是 $2^{bit}$（因为 $0+1=1$，而 $1+0$ 同理）。但注意这里加的其实是 "和" 而不是 "异或和"——所以 $X$ 中每个为 $1$ 的位，在 $S_1 + S_2$ 中都恰好贡献 $2^{bit}$。

因此：**$X$ 的所有位，无论 $0$ 还是 $1$，我们都需要分别考虑其对「和」的贡献。**

重新整理思路：
- 最终答案 = $S_1 + S_2$
- 并且 $S_1 \oplus S_2 = X$
- 我们希望最大化 $S_1 + S_2$

### 观察 3：逐位贪心

对于 $X$ 中为 $1$ 的位：$S_1$ 和 $S_2$ 在该位上必然是一个 $0$、一个 $1$。它们对「和」的贡献是 $2^{bit} \times 1 = 2^{bit}$，这部分**不可改变**。

对于 $X$ 中为 $0$ 的位：$S_1$ 和 $S_2$ 在该位上要么都是 $0$，要么都是 $1$。如果是两个 $1$，对和的贡献是 $2 \times 2^{bit}$；如果是两个 $0$，贡献为 $0$。

因此，**我们希望 $X$ 中为 $0$ 的那些位上，$S_1$ 和 $S_2$ 都尽量为 $1$**。

---

## 问题转化

设 $msk$ = $X$ 中所有为 $0$ 的位组成的掩码（即 $msk = \neg X$，取低 $30$ 位）。

对于每个 $A_i$，令 $B_i = A_i \mathbin{\&} msk$（只保留 $X$ 中为 $0$ 的位）。

问题转化为：**从 $B$ 中选出一个子集，使其异或和最大**。

为什么呢？

- 设我们选出的子集的异或和为 $Y$，则两个集合的异或和分别是 $Y$ 和 $X \oplus Y$
- $S_1 + S_2 = Y + (X \oplus Y)$
- 在 $X$ 为 $1$ 的位上，$Y$ 和 $X \oplus Y$ 总是一个 $0$ 一个 $1$，贡献固定
- 在 $X$ 为 $0$ 的位上，两者相同：如果 $Y$ 在该位为 $1$，贡献 $2 \times 2^{bit}$；如果 $Y$ 在该位为 $0$，贡献 $0$
- 因此**最大化 $Y$（在 $msk$ 范围内的值）就等价于最大化最终答案**

---

## 异或线性基（XOR Linear Basis）

### 什么是线性基

线性基是一组向量（这里是数的二进制表示），使得：
1. 原集合中任意子集的异或和，都可以用线性基中若干元素的异或和表示
2. 线性基的大小不超过 $\log M$（这里 $M = 2^{30}$，即最多 $30$ 个元素）

### 如何构造

从高位到低位遍历每个数，对于每个数：
- 如果当前最高位在线性基中还没有对应元素，则插入
- 否则，用已有的线性基元素消去该位，继续处理下一个低位

```cpp
// 插入一个数到线性基
void insert(int x, vector<int>& basis) {
    for (int i = 29; i >= 0; i--) {
        if (!(x >> i & 1)) continue;
        if (!basis[i]) {
            basis[i] = x;
            return;
        }
        x ^= basis[i];
    }
}
```

### 如何求最大异或和

从高位到低位贪心：如果当前答案异或上该位的线性基元素能让答案变大，就异或。

```cpp
int max_xor(vector<int>& basis) {
    int res = 0;
    for (int i = 29; i >= 0; i--) {
        if (basis[i] && !(res >> i & 1))
            res ^= basis[i];
    }
    return res;
}
```

## 完整算法

1. 计算 $X = A_1 \oplus A_2 \oplus \cdots \oplus A_n$
2. $msk = (\text{所有 } 30 \text{ 位均为 } 1) \oplus X$，即 $msk = (1 \ll 30) - 1 - X$
3. 对每个 $A_i$，计算 $B_i = A_i \mathbin{\&} msk$
4. 将所有 $B_i$ 插入异或线性基
5. 从线性基中求出最大可达的异或和 $Y$
6. 答案 = $Y + (X \oplus Y)$

### 为什么 $B_i = A_i \mathbin{\&} msk$ 可行？

关键：**按位与（AND）对异或（XOR）满足分配律**。

$$
(x \oplus y) \mathbin{\&} msk = (x \mathbin{\&} msk) \oplus (y \mathbin{\&} msk)
$$

因为 AND 和 XOR 都是逐位独立的运算：对于每一个 bit，AND 是乘法（$\times$），XOR 是模 2 加法（$+ \bmod 2$），乘法对加法自然有分配律。

于是对于任意子集 $S$：

$$
\begin{aligned}
Y \mathbin{\&} msk
&= \left(\bigoplus_{i \in S} A_i\right) \mathbin{\&} msk \\
&= \bigoplus_{i \in S} (A_i \mathbin{\&} msk) \qquad \text{(分配律)} \\
&= \bigoplus_{i \in S} B_i
\end{aligned}
$$

**这意味着**：你想在 $A$ 的异或空间里找到某个异或值 $Y$，它在 $msk$ 位上的值，**恰好等于对应 $B_i$ 的某子集的异或和**。

不存在"B 中能异或出来的值在原数组中异或不出来"的问题——用同一个子集 $S$ 在 $A$ 上做异或，$msk$ 位的结果就是 $B$ 的对应异或值。$B$ 的线性基**完整且无损地**刻画了我们在 $msk$ 位上能达到的所有可能。



**计算 $A \oplus B$ (不进位加法部分):**

$$X \oplus (S \oplus X) = S$$

（因为 $X \oplus X = 0$。这说明无论你怎么选子集，$X + (S \oplus X)$ 的基础盘一定是 $S$）。

**计算 $A \ \& \ B$ (进位部分):**

我们需要计算 $X \ \& \ (S \oplus X)$。

我们可以按位来思考，假设当前看的是第 $k$ 位：

- 如果 $S$ 的第 $k$ 位是 `1`：那么 $X$ 和 $S \oplus X$ 在第 $k$ 位上的值必定**一个是 0，一个是 1**。它们的 `&` 结果必定是 **0**。
- 如果 $S$ 的第 $k$ 位是 `0`：那么 $X$ 和 $S \oplus X$ 在第 $k$ 位上的值必定**完全相同**。它们的 `&` 结果就等于 **$X$ 的第 $k$ 位**。

由此可以得出一个极其重要的结论：

**$X \ \& \ (S \oplus X)$ 的结果，就等于把 $X$ 中所有对应 $S$ 为 1 的位全部清零，只保留对应 $S$ 为 0 的位。**

用代码语言表达就是：

$$X \ \& \ (S \oplus X) = X \ \& \ (\sim S)$$



### 为什么可以直接把 `a[i] & (~S)` 插入线性基？

因为 $S$ 对于确定的数组来说是一个**常数**。

想要最大化 $\text{Score} = S + 2 \times (X \ \& \ (\sim S))$，唯一的变量就是后面的部分，我们只需要**最大化 $X \ \& \ (\sim S)$** 即可。

由于按位与（`&`）和按位异或（`\oplus`）在特定条件下满足分配律：

对于原数组的任意子集，其异或和去 `& (~S)`，等价于**先把子集里的每一个数先去 `& (~S)`，然后再全部异或起来**。

即：

$$(a_1 \oplus a_2 \oplus \dots) \ \& \ (\sim S) = (a_1 \ \& \ (\sim S)) \oplus (a_2 \ \& \ (\sim S)) \oplus \dots$$

## 复杂度分析

- 线性基大小：$O(\log M) = O(30)$
- 每插入一个数：$O(30)$
- 总复杂度：$O(n \cdot \log M)$，即 $O(30n)$

对于 $\sum n \leq 5 \times 10^5$，运算量约为 $1.5 \times 10^7$，完全可行。

## 举例说明

### 样例 3：$n=4, A=[1,1,3,3]$

1. $X = 1 \oplus 1 \oplus 3 \oplus 3 = 0$
2. $msk = (1 \ll 30) - 1$（全为 $1$，因为没有位被 $X$ 占用）
3. $B = [1, 1, 3, 3]$
4. 线性基：$1(001), 3(011)$ → 最大异或和 $Y = 1 \oplus 3 = 2$？不对——
   - 插入 $1$：basis[0] = 1
   - 插入 $1$：$1 \oplus 1 = 0$，跳过
   - 插入 $3$：最高位是第 1 位，basis[1] 为空，basis[1] = 3
   - 插入 $3$：$3 \oplus 3 = 0$，跳过
   - 从高到低贪心：res=0 → res^3=3 → res=3 → 第0位res已经是1，跳过basis[0]=1
   - 最大 $Y = 3$
5. 答案 = $Y + (X \oplus Y) = 3 + (0 \oplus 3) = 3 + 3 = 6$ ✅

### 样例 4：$n=4, A=[1,2,2,3]$

1. $X = 1 \oplus 2 \oplus 2 \oplus 3 = 0$（$2 \oplus 2 = 0$）
2. $msk$ 全为 $1$
3. $B = [1, 2, 2, 3]$
4. 线性基：basis[1]=2, basis[0]=1 → 最大异或和 $Y = 3$
5. 答案 = $3 + 3 = 6$？等等，样例输出是 $4$——

   重新算：$X = 1 \oplus 2 \oplus 2 \oplus 3$
   - $1 \oplus 2 = 3$
   - $3 \oplus 2 = 1$
   - $1 \oplus 3 = 2$
   - 所以 $X = 2$

6. $msk$ = 去掉第 1 位（bit 1 在 $X$ 中为 $1$）
   - $msk = \ldots 11101$（bit 1 为 0）
7. $B = A \mathbin{\&} msk$
   - $1(001) \mathbin{\&} msk = 1$
   - $2(010) \mathbin{\&} msk = 0$
   - $2(010) \mathbin{\&} msk = 0$
   - $3(011) \mathbin{\&} msk = 1$
8. 线性基：basis[0] = 1
9. 最大 $Y = 1$
10. 答案 = $Y + (X \oplus Y) = 1 + (2 \oplus 1) = 1 + 3 = 4$ ✅

## 参考代码框架

```cpp
#include <bits/stdc++.h>
using namespace std;

const int B = 30;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    int X = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        X ^= a[i];
    }
    
    int msk = ((1 << B) - 1) ^ X;  // X 中为 0 的位
    
    vector<int> basis(B, 0);
    for (int x : a) {
        int v = x & msk;
        for (int i = B - 1; i >= 0; i--) {
            if (!(v >> i & 1)) continue;
            if (!basis[i]) { basis[i] = v; break; }
            v ^= basis[i];
        }
    }
    
    int Y = 0;
    for (int i = B - 1; i >= 0; i--) {
        if (basis[i] && !(Y >> i & 1))
            Y ^= basis[i];
    }
    
    cout << Y + (X ^ Y) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```

## 总结

| 步骤 | 内容 |
|------|------|
| 关键洞察 | $S_1 \oplus S_2 = X$（常数），$X$ 为 $1$ 的位贡献固定，只需最大化 $X$ 为 $0$ 的位 |
| 转化 | 用 $msk$ 过滤 $A_i$，转化为求子集最大异或和 |
| 工具 | 异或线性基（XOR Linear Basis） |
| 复杂度 | $O(n \log M)$，其中 $M = 2^{30}$ |
