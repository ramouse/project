# L 题 - 懒惰洗牌（Lazy Shuffling）

## 题目大意

对于一个长度为 $n$ 的排列 $A = [A_1, A_2, \ldots, A_n]$，用另一个长度为 $n$ 的排列 $p = [p_1, p_2, \ldots, p_n]$ 将其打乱成 $[A_{p_1}, A_{p_2}, \ldots, A_{p_n}]$。

问有多少个 $A$ 能**最大化**打乱前后逆序对之差的绝对值？结果对 $998244353$ 取模。

- $n \leq 22$

---

## 核心观察

### 观察 1：只有 $p$ 的逆序对影响结果

对于一对下标 $1 \leq i < j \leq n$，考虑它们在打乱后对应位置的值 $A_{p_i}, A_{p_j}$：

- 如果 $p_i < p_j$：打乱前后这两个元素的相对顺序不变，要么都形成逆序对，要么都不形成。因此**不影响**逆序对之差。
- 如果 $p_i > p_j$（即 $(i,j)$ 是 $p$ 的一个逆序对）：
  - 若 $A_{p_i} > A_{p_j}$：打乱后不再是逆序对（因为 $p_i$ 和 $p_j$ 在 $A$ 中的顺序被颠倒了），**贡献 +1**
  - 若 $A_{p_i} < A_{p_j}$：打乱后变为逆序对，**贡献 -1**

所以，**只需关注 $p$ 的逆序对**，每个逆序对对最终差的贡献是 $\pm 1$。

### 观察 2：可以让所有贡献同向

$A = [1, 2, \ldots, n]$ 就是一个使所有贡献同向的排列——此时对 $p$ 的每个逆序对 $(i,j)$，由于 $p_i > p_j$ 且 $A_{p_i} > A_{p_j}$ 必然成立（$A$ 是递增的），所有贡献都是 +1。

同理 $A = [n, n-1, \ldots, 1]$ 使所有贡献都是 -1。

因此**最大绝对值 = $p$ 的逆序对个数**。

### 观察 3：问题转化为求合法拓扑序个数

我们希望 $A$ 满足：对于 $p$ 中所有逆序对 $(i,j)$，要么全部 $A_{p_i} < A_{p_j}$，要么全部 $A_{p_i} > A_{p_j}$。

这等价于：根据这些大小关系建立一个有向图（从小指向大），然后求这个有向图的**拓扑序个数**。

---

## DP 求解拓扑序个数

设 $dp[S]$ 表示子集 $S$（用 $[0, 2^n)$ 的一个数表示）中顶点的拓扑序个数。

转移：从 $S$ 中选一个没有入边（来自 $S$ 外部）的点 $u$ 作为拓扑序的下一个位置：

$$dp[S] = \sum_{u \in S, \text{in-degree}_S(u) = 0} dp[S \setminus \{u\}]$$

对于入边的判断，可以预处理每个点 $u$ 的入边集合 $mask[u]$（哪些点有边指向 $u$），然后判断 $(mask[u] \mathbin{\&} S) = 0$ 即可 $\mathcal{O}(1)$ 完成。

边界：$dp[0] = 1$。

### 两个图的关系

$A_{p_i} < A_{p_j}$ 和 $A_{p_i} > A_{p_j}$ 对应的图恰好**边方向全部相反**。因此一个图的拓扑序反转就是另一个图的拓扑序，两者**一一对应**。只需计算其中一种即可，答案乘以 2。

### 特殊情况

如果 $p$ 本身**没有逆序对**（即 $p = [1,2,\ldots,n]$），那么无论如何划分都不会有逆序对变化，**每个排列都满足要求**，答案直接是 $n!$。

> 如果 $p$ 有逆序对但两个条件（全正和全反）同时满足时，图中会出现环（矛盾），此时会重复计算。但可以证明：只有当 $p$ 没有逆序对时才可能同时满足，已作为特殊情况处理。

---

## 算法步骤

1. 检查 $p$ 是否有逆序对，若无则输出 $n!$
2. 预处理每个点的入边掩码 $mask[u]$
3. DP：$dp[0] = 1$，枚举 $S$ 从 $1$ 到 $2^n - 1$
4. 对于每个 $S$，找到所有入度为 $0$ 的点 $u$，累加 $dp[S \setminus \{u\}]$
5. 答案 = $dp[2^n - 1] \times 2 \bmod 998244353$

---

## 复杂度分析

- 状态数：$2^n$
- 每个状态枚举可能的点：$O(n)$
- 总复杂度：$O(n \cdot 2^n)$

对于 $n \leq 22$：$22 \times 2^{22} \approx 9.2 \times 10^7$，可行。

---

## 举例说明

### 样例：$n=3, p=[2,3,1]$

$p$ 的逆序对：$(2,1)$ 即 $(p_1 > p_3)$，$(3,1)$ 即 $(p_2 > p_3)$。

建立有向图（要求 $A_{p_i} < A_{p_j}$ 对于所有逆序对）：
- $A_{p_3} < A_{p_1}$ 即 $A_1 < A_2$
- $A_{p_3} < A_{p_2}$ 即 $A_1 < A_3$

边：$1 \to 2$，$1 \to 3$。

拓扑序个数：$1$ 必须在最前面，$2$ 和 $3$ 随意 → $2$ 种（$[1,2,3]$ 和 $[1,3,2]$）。

反向图的拓扑序也有 $2$ 种。总共 $4$ 种，即 $dp[2^3-1] \times 2 = 2 \times 2 = 4$。

## 参考代码框架

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    vector<int> p(n);
    for (int i = 0; i < n; i++) cin >> p[i];
    
    // 检查 p 是否有逆序对
    int inv_cnt = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (p[i] > p[j]) inv_cnt++;
    
    if (inv_cnt == 0) {
        // 每个排列都满足条件
        ll fact = 1;
        for (int i = 2; i <= n; i++)
            fact = fact * i % MOD;
        cout << fact << '\n';
        return 0;
    }
    
    // 建立入边掩码（A_pi < A_pj 的情况）
    vector<int> mask(n, 0);
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (p[i] > p[j])  // (i,j) 是 p 的逆序对
                mask[p[j] - 1] |= (1 << (p[i] - 1));  // 大 → 小的边
    
    vector<ll> dp(1 << n, 0);
    dp[0] = 1;
    
    for (int S = 1; S < (1 << n); S++) {
        for (int u = 0; u < n; u++) {
            if (!(S >> u & 1)) continue;
            if (mask[u] & S) continue;  // 还有入边在 S 中
            dp[S] = (dp[S] + dp[S ^ (1 << u)]) % MOD;
        }
    }
    
    ll ans = dp[(1 << n) - 1] * 2 % MOD;
    cout << ans << '\n';
    return 0;
}
```
